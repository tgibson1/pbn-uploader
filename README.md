# Passport Bro News Uploader

A private, internal tool used only by the owner of the **Passport Bro News** YouTube channel
(https://www.youtube.com/@PassportBroNews) to upload and schedule that channel's own videos.

After the owner reviews and approves a finished video in a local dashboard, the tool uploads it with its
title, description, tags, thumbnail and captions, schedules its publish time, and uploads a short preview
clip that links to it. It runs only on the owner's computer. It has no other users and is not offered to anyone.

It uses YouTube API Services. See the [Privacy Policy](PRIVACY.md).
