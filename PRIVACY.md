# Passport Bro News Uploader: Privacy Policy

Effective 11 November 2026

Passport Bro News Uploader ("the tool") is a private tool used only by the owner of the Passport Bro News
YouTube channel to upload and schedule videos to that channel.

## What data it accesses
With the channel owner's permission, given through Google OAuth, the tool:
- uploads videos, thumbnails and captions to the owner's own channel and adds them to the owner's playlists;
- reads the channel's name and ID, to confirm the right account is signed in.

It does not access any other user's data.

## Where data is stored
The sign-in token and the IDs of uploaded videos are stored only on the owner's own computer.
Nothing is stored on any server operated for the tool.

## Sharing
No data is sold, shared with third parties, or used for advertising. The tool has no users other than the channel owner.

## Revoking access and deleting data
- Access can be revoked at any time at https://myaccount.google.com/permissions (Google Account → Security →
  Third-party connections). Revoking stops the tool from making any further requests.
- The tool keeps no data on any server. To delete everything it stores, delete the sign-in token folder on the
  owner's computer (%APPDATA%\PassportBroNews\youtube-token) and the youtube.json files in the episode folders.
  Deleting them removes all stored tokens and video IDs immediately.
- Stored data is kept only as long as the owner uses the tool. Authorization data obtained from YouTube API
  Services is refreshed or deleted at least every 30 days, as the YouTube API Services Developer Policies require.
- Videos uploaded to YouTube are managed in YouTube Studio and can be deleted there at any time.

## YouTube and Google
This tool uses **YouTube API Services**. By using it, you agree to be bound by the YouTube Terms of Service
(https://www.youtube.com/t/terms). Google's handling of data is described in the Google Privacy Policy
(https://policies.google.com/privacy).
